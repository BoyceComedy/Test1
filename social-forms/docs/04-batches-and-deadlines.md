# 4. Batches and deadlines

Jobs come in as **batches**, so there's a deadline to meet.

Making a social is instant once the content is right. The deadline exists to protect the designers' time: to review, fix and get images. It also helps with the number of jobs coming in.

## Rules

| Rule | Value |
| --- | --- |
| Lead time | Content due **3 working days** before go-live |
| Too-soon go-live | Can't be picked |
| After cut-off | Batch locks for marketers; only designers can change it |
| Busy week | **Warning only.** If a week has more socials than the set level, marketers see a warning but can still book it. |

The designer can change the lead time and the warning level on the Settings tab.
