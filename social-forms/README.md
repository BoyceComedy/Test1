# Social forms

Input forms and rule set-up for the social creative app.

This project covers **the input only**: where marketers enter the content of a social, and where the designer sets up what each template allows. It does not make artwork. The social creative app does that.

## What's in here

| File | What it is |
| --- | --- |
| `designer-tick-sheet.xlsx` | The sheet the designer fills in to set the rules. Ticks, not written rules. |
| `docs/01-scope.md` | What we're building and what we're not |
| `docs/02-structure.md` | Batch → Social → Slide, and every field |
| `docs/03-rules.md` | How the rules work and how the tick sheet maps to them |
| `docs/04-batches-and-deadlines.md` | Deadlines, lead time and the busy-week warning |
| `docs/05-platform.md` | SharePoint, Windows/Mac, and options for the form |
| `docs/06-open-questions.md` | What's still to decide |

## The problem in one line

Marketers fill in everything and often get it wrong, so the designer fixes it while making the social. The form should put the right information in the right place, so a correct social can be made straight away.
